# Fallback Skills

## brainstorming

Esta skill nao esta disponivel no toolkit atual.
Para gerar hipoteses a partir de dados, usar:

1. Listar padroes observados (minimo 3 ocorrencias para considerar padrao).
2. Para cada padrao, formular 2-3 hipoteses concorrentes de causa raiz.
3. Classificar hipoteses por facilidade de teste (rapido de validar primeiro).
4. A hipotese mais testavel vira o proximo experimento.
